## 内容与版本

- docs：文档总包 V1.6，含 158 张当前配图、历史参考、供应商线索、统一设计源与验证记录。
- patent：专利技术交底书 V1.0，含 7 张附图。
- 全部原始资料保留；只在仓库副本中适配网页导航及相对链接。每份 Markdown 都有同目录 HTML 阅读副本。
- source-manifest.json 是导入前原稿校验清单；总包内原有校验记录反映当时版本，不代表本次网页适配后的哈希。
- 历史资料按原有说明保留；产品设计与未实测事项以现行章节为准。

## 本地预览

直接打开 index.html 即可离线阅读。也可在仓库根目录执行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8080/ 。

## Pages 部署入口

GitHub Pages 从 main 分支的 / (root) 发布。根目录 index.html 为文档中心入口，.nojekyll 保留静态文件路径。后续推送到 main 后，由 GitHub Pages 自动构建并更新网页。
