# T14｜异常工单与实物交接

一份表对应一个caseId；责任转派必须被实际接收，未签收前原责任不解除。参照[21章第9—10节](../21_端到端逻辑闭环与验收矩阵.md)。

| 记录项 | 实际填写 |
|---|---|
| caseId／原任务／回执／资产或unknownItemRef／轮次 | 待填写 |
| 发现时间、原因、物理位置、卫生状态及隔离位 | 待填写 |
| 责任角色、实际接单人、主管及接收时间 | 待填写 |
| T_ack／T_resolve／T_pickup签核版本、具体到期时间 | 待填写 |
| 当前通道限制、实物保管措施、用户可查询回执 | 待填写 |
| 交接人／接收人／时间／物体清单及差异／签收 | 待填写 |
| 证据引用、原始观察、不能确定的事实 | 待填写 |
| 超期与升级记录、新期限、原超期保留 | 待填写 |
| 判定：已交付／未交付／归还／无借用收件／政策处置 | 待填写 |
| 审批人及权限范围、原事实与补正后的账务 | 待填写 |
| 实物最终去向或批准损失／报废，未结子单 | 待填写 |
| 预留、在借、周期量变化及规则依据 | 待填写 |
| 用户通知／可查询结果与审计标识 | 待填写 |
| 业务关单条件与签核 | 未关闭 |
| 本地安全复验、通道清场及恢复签核 | 未恢复 |

证据不足继续争议处理，不能凭超时自动销账或收费。政策豁免不冒充实物归还；资产位置仍未知时必须保留有关联且有责任人的未结差异单。迟到证据与已签结论冲突时重开关联工单并追加修正。

### 2026-09-20｜离线建单与人工补正补充

参照[21章第14节](../21_端到端逻辑闭环与验收矩阵.md)。caseId尚未建立时，先以设备作用域下的localIncidentId登记同一份异常记录，caseId栏留空并标待同步；恢复后填写映射，不另造第二份实物记录。

| 补充记录项 | 实际填写 |
|---|---|
| localIncidentId／设备与存储实例作用域／同步状态／关联caseId | 待填写 |
| 发现时间及可信度／平台收到／平台建单／实际接单时间 | 待填写 |
| 离线滞留时长或未知原因／人工发现与升级／时间证据 | 待填写 |
| maintenanceSessionId／原任务与通道周期／柜端接管确认及版本 | 待填写 |
| 取走判定与维护接管先后／原始传感器变化／交接观察 | 待填写 |
| reconcileRequestId／请求摘要／预期和实际businessResultVersion | 待填写 |
| 自动事件与人工补正竞争／版本冲突／重读后处理 | 待填写 |
| 迟到证据与原结论差异／重开关联单／追加补偿及审计 | 待填写 |

离线记录不等于平台已派单；授权取出不等于未交付已获证明；补正提交成功不等于本地安全复验完成。
