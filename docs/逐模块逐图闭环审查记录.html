02｜产品需求与毛巾规格

小节 核对结论及失败出口
1. 范围与使用者 住户、物业、维修、清洗责任不同；离线新领还均不进入首期。
2. 可追溯需求 R01—R14映射设计与证据；许可、安全和权限失败均阻断相应动作。
3. 毛巾是机械系统的一部分 真实样本与折法先冻结；偏离范围回采样，不拿概念尺寸下单。
4. 服务容量与补货 位置、卫生、责任分维度；补货准入及移出差异没核清不恢复。
5. 首期建议业务规则 代还锁原轮次，额度三量分开；现场自然人身份仍由D09处理。

04｜内部机械结构与传动

小节 核对结论及失败出口
1. 总剖面怎么理解 H01—H09拆解含工作、参数、维护及复装验证；图形不代表CAD已完成。
2. 电机如何把毛巾送出来 电机经联接、轴承、滚筒至平带；驱动轴支撑与保护由工程图核定。
3. 单条分离的关键矛盾 底条通行与上层保持同时通过才有分离窗口；单EPC不是条数真值。
4. 什么时候停M1：必须验证的核心 满／半／近空测试停车与后条位移；未见S1不直接当空仓，失败不盲重试。
5. 读区和出口不是画个框就够 候选身份、本条许可、本地安全、实际交付依次确认；旧概念图不当触发规范。
6. 电机计算示例：不作为采购规格 扭矩与带速计算是示例；拉力、效率、动态与温升实测后才能采购。

06｜RFID与毛巾身份验证

小节 核对结论及失败出口
1. 直观理解 RFID提供标签身份，不证明人、条数、含水量或实物交付。
2. 身份规则 独立资产、EPC历史、换标关联连续；未知身份不新建资产抹平差异。
3. 发放读区 目标可读与库存／邻柜不可串读同时满足；无许可仍不能释放。
4. 选品必须索要的数据 耐洗与湿读证据分开索取；型号、工艺和洗涤条件相符才纳入选型。
5. 标定与挑战测试 参数按真实姿态和干湿挑战冻结；失配回布局／保持区后复验。

07｜湿巾归还与洗涤闭环

小节 核对结论及失败出口
1. 回收小仓的实际作用 在线入口回执先于投放；无人投放须门关仓空并封禁后终止。
2. 受控动作顺序 七步互锁包含原轮次、箱批次与容量预留；缺条件保持不盲落。
3. 无法识别怎么处理 未知单件位置、指派、接单和期限分开；无隔离能力则停该通道。
4. 防错场景 转移前与不可逆转移后失联分开；证据不能改变实际箱位置。
5. 清洗到补货 QC不合格返洗／修复／报废；业务冻结湿物按时限有签收地转运。

4. 现场验收用例 S项与C项现场复核；测试环境证据不自动证明实际物业条件。
5. 培训与试运营 人员培训、故障演练和实际服务数据后再放量；关键风险停用。
6. 交接与退出 资料签收、未决清单、恢复条件完整；扩点由复盘决定。
