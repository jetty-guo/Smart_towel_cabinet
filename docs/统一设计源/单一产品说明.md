# 一台产品，一套空间关系

V1.6 / LVT-ONE。按用户指出的单柜外形纠正旧稿，不再把不同外壳混在当前产品中。

## 已统一的外观与结构

- 银灰单柜，Liveo左上，二维码及圆形绿灯右上；没有显示屏或外置回收副柜。
- 左上领巾口：一条折叠净巾；对应H08固定取物斗，背后是H07内部释放件。
- H01库存位于左上净巾舱后部；M1、M2沿柜深从后向前运动。H07前端交付，不能把送料线横向贯穿湿舱。
- 右下归还口：后接R01单件识别仓、R02内部转移分流；E01在右上单独干燥舱。
- 底部服务门：R03正常回收箱、R04单件异常箱分别抽出；R04占用时未知物留R01并停收。
- 主服务门后有独立净舱、电舱、回收内罩。主门轮廓不表示净污区域可以敞开相通。

## 唯一布局源

[单一产品布局.json](单一产品布局.json)定义统一坐标。x从左向右，y从正面向背面，z从底面向顶部；模块使用[x,y,z,宽,深,高]。

数字是归一化布局单位，不是毫米。技术图使用相同投影，不允许每张图独立缩放某一个模块来假装装得下。生产尺寸必须将同一W/H/D换算为毫米后，以实际零件、毛巾运动姿态、材料厚度、装配公差、门扇及可维护空间检查。效果图来自同一外观母图，仍会有透视与渲染误差，不能用于数值测量。

## 制造前必须实测闭合

| 项目 | 通过条件 | 不通过的处理 |
|---|---|---|
| 柜深 | M1/料仓、过渡、M2保持、H07/H08、前后板与余量能共同装入 | 同一母图统一变更，不能局部拉长 |
| 保持长度 | 最大运动展开长度＋停距＋定位余量≤有效保持长度 | 改进折叠保持/导向或统一空间，不宣称已单条可靠 |
| 容量 | 可用堆高÷实测受压厚度，并经满/半/近空验证 | 调整补货周期或统一布局；不从效果图估算条数 |
| 回收抽箱 | 正常/异常箱通过同一个底门且不跨过净舱 | 核门净开口、抽出轨迹、箱位检测 |
| 分流 | 含水软巾可靠转移到指定容器；R04一次一件 | 保持停收、人工追溯，退回结构整改 |
| 防护与卫生 | 防触及、拉拽、失电、净污隔板/密封和排液验证 | 禁止按外观一致判定安全通过 |

本轮完成的是设计表达统一。尚无已批准的制造CAD、公差分析、样机装配记录或上述试验结果，不能据此直接下钣金生产单。

## 修改和失效管理

修改布局源→重生成三视/剖面/拆装→更新同母图场景→核对BOM与I/O→记录T11→复验→整包一起发布。外观、机构、场景不得独立发布。

旧稿完整保存于上一级V1.5备份ZIP；已撤回旧图片保存在历史参考文件夹，不进入当前图册。V1.4全文审查和V1.5采购审查只证明当时的检查范围，不是本轮几何一致性证明。

## 图形源文件的复用

`重生成结构图.py`读取本目录的布局JSON，重生成22张基础结构/定位图；它不自动重生成场景效果图、4张说明流程图、图163或HTML。修改后需同步相关图、当前配图目录与阅读页并重跑检查。局部详图原生源用于再生成定位条，不属于当前图册。效果图生成提示词及参照见本目录JSON记录。
